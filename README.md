# 해서 → 소전 변환기 (楷書 → 小篆)

<https://meditator-farm.github.io/sojeon/>

해서(楷書)를 입력하면 소전(小篆)으로 바꿔 보여주는 웹앱입니다. 휴대폰 홈 화면에 앱으로 설치해 쓸 수 있습니다.

- **사진으로 찾기**: 책·자료를 찍으면 AI(Claude API)가 한자를 읽고, 틀린 글자는 고쳐서 소전으로 바꿉니다. 서버 설정은 [`worker/README.md`](worker/README.md)를 보세요.
- **음·훈으로 찾기**: "천", "하늘"처럼 음이나 뜻으로 해서를 찾습니다.
- **손글씨로 찾기**: 손가락으로 써서 찾습니다.
- **부수·획수로 찾기**: 음·뜻을 모르는 벽자도 찾을 수 있습니다.
- **글자 풀이**: 대응표에서 글자를 누르면 기초자 설명 → 자형 분해(540부수 분해표) → 소전 해독(기본자형의 뜻으로 훈 짓기) 순으로 이어서 볼 수 있습니다.
- **기초자 · 說文 540부수 자형 분해표**: 최규화 님의 자료를 저자의 허락을 받아 게시합니다.
- **說文 원본 소전**: 崇羲篆體字形表(《說文解字》)의 소전 그림을 함께 보여줍니다.
