# 손글씨 인식 (hwr)

이 폴더의 파일은 손글씨로 한자를 찾는 기능에 쓰입니다.

| 파일 | 내용 | 라이선스 |
|---|---|---|
| `hanzilookup.min.js` | 손글씨 인식 프로그램 (`src/`를 이어 붙여 압축한 것) | GNU GPL v3 (`LICENSE-GPL.txt`) |
| `src/` | 위 프로그램의 원본 소스 코드 | GNU GPL v3 (`LICENSE-GPL.txt`) |
| `orig.json` | 획 자료 (Jordan Kiang의 HanziLookup 원본) | GNU GPL v3 (`LICENSE-GPL.txt`) |
| `mmah.json` | 획 자료 (Make Me a Hanzi, Arphic 글꼴에서 만듦) | Arphic Public License (`LICENSE-APL.txt`) |

출처: [HanziLookupJS](https://github.com/gugray/HanziLookupJS) (Gábor L Ugray, 커밋 b21124f) — Jordan Kiang의 [HanziLookup](http://kiang.org/jordan/software/hanzilookup)을 바탕으로 한 프로그램입니다.
